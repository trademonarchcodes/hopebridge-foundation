# HOPEBRIDGE FOUNDATION

**Building Hope. Changing Lives.**

A responsive, multi-page public website for HOPEBRIDGE FOUNDATION.

## Project structure
- `index.html` — homepage
- `about.html` — mission, vision and values
- `causes.html` — six proposed humanitarian focus areas
- `campaigns.html` — campaign information
- `donate.html` — giving information and pre-launch donation notice
- `impact.html` — impact reporting framework
- `get-involved.html` — ways to participate
- `stories.html` — news and stories
- `contact.html` — contact information and enquiry preview
- `transparency.html` — accountability information
- `assets/css/style.css` — shared responsive styles
- `assets/js/main.js` — navigation and interface interactions

## Local preview
Open `index.html` in a browser. The site uses static HTML, CSS and JavaScript and has no build step or paid dependencies.

## Cloudflare Pages
Connect this GitHub repository to Cloudflare Pages. Select the `main` branch, leave the build command blank, and set the build output directory to `/`.

## Before public launch
Replace pending information with verified official details. Confirm the foundation's legal status, official contact channels, actual programmes, campaign details and authorized donation/payment arrangements. Donation processing is intentionally not enabled. Do not publish unverified impact figures, testimonials, targets or claims.

The contact form is a non-submitting preview until an official inbox/backend is connected. Images currently load from Unsplash URLs and require an internet connection.
